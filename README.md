# 月面航迹 LunarNav

基于 NASA LRO WAC 月面影像与 LOLA 全球高程数据制作的浏览器端月球表面导航 demo。

## 使用

直接用本地静态服务器打开 `dist/`。应用包含：

- 可任意方向拖拽的球体月球，表面有全球 5° × 5° 网格；
- 全球 2,592 个分片均可直接在球体上点击选取，也可输入经纬度；
- 基于 LRO WAC 影像、LOLA 高程的细粒度地形与坡度可视化；
- 点击“起点”“终点”“增加途经点”后直接在地图上选点；
- 有序途经点规划，以及 2–8 个无序目标点的最短访问顺序规划；
- 二维 / 三维地形视图、可调高程夸张系数、高程剖面与航迹 JSON 导出。

数据来源：NASA Scientific Visualization Studio 的 CGI Moon Kit。构建脚本 `tools/prepare_global.py` 将 LOLA 全球 64 px/° 高程图平均至 32 px/°，按纬度打包供浏览器按需读取；每个 5° 分片约有 160 × 160 个采样点。5° 分片是此应用自定义的交互网格，并非声称是 NASA 原始数据的分片方式。三维视图以月球半径和分片实际水平尺度为基础，默认使用 4 倍高程夸张以保持地形可辨识。该原型仅用于科研展示，不用于真实月面任务决策。
