# 月面航迹 LunarNav

基于 NASA LRO WAC 月面影像与 LOLA 全球高程数据制作的浏览器端月球表面导航 demo。

在线体验：[月面航迹 · LunarNav](https://yanshi42.github.io/lunar-nav-demo/)

长期沿用上述GitHub Pages地址，旧Sites地址保留历史原版。

## Head 全月撞击坑参考图层（2026-10-25）

Head目录的全部5185条记录已作为独立图层接入，默认以粉紫色参考圆显示，可单独开关；全球旋转视图、分片二维和三维导航都可查看。支持按目录编号检索、点击圆线或中心查询经纬度与直径、定位到对应分片，并下载完整CSV。该目录覆盖全月，不受16片WAC模型预测范围限制；跨分片只裁剪显示线段，不生成假的边框。

数据采用[DeepMoon固定版本的HeadCraters.csv](https://github.com/silburt/DeepMoon/blob/0bccc9790bbf02b3c1df33bd0f452d87b136dc9d/catalogues/HeadCraters.csv)，对应[Head等（2010）发表的≥20km目录](https://doi.org/10.1126/science.1195050)。全部原始经度、纬度和直径均按CSV数据行顺序保留，SHA256为`6bb968015a43d16874311aedfc43168c57bcc561f37afdc566870958f238e46a`；转换后的表格来自DeepMoon，来源和许可随网页资产提供。

参考圆按1737.4km月球球体上的中心及半径生成，并非人工描绘的坑缘。`Head-00001`等编号是本网页按CSV数据行赋予的标识，不是IAU正式地名。该参考图层不是模型预测，也不建立模型独立精度验收。

复现与验证：`tools/prepare-head-catalog.py`构建资产，`tools/verify-pages-assets.py`逐行核对完整目录，`tools/verify-head-geometry.mjs`独立检查全部记录的半径及极区、跨经线和立方体接缝裁剪，`tools/verify-head-layer.py`覆盖真实浏览器的六向全球显示、查询下载、二维/三维、南北极、跨经线、大盆地和移动端。


临时服务器的4173端口已按用户要求关闭（2026-10-23）；原服务器地址目前不提供服务。上方原始 Sites 链接保留原版内容。

## 使用

在仓库根目录运行 `python -m http.server 4173 --directory dist`，然后打开 `http://localhost:4173/`。应用包含：

- 可任意方向拖拽的球体月球，表面采用六面球面近等面积方格网；
- 全球 1,944 个分片均可直接在球体上点击选取，也可输入经纬度；
- 基于 LRO WAC 影像、LOLA 高程的细粒度地形与坡度可视化；
- 点击“起点”“终点”“增加途经点”后直接在地图上选点；
- 有序途经点规划，以及 2–8 个无序目标点的最短访问顺序规划；
- 二维 / 三维地形视图、可调高程夸张系数、高程剖面与航迹 JSON 导出。

数据来源：[NASA Scientific Visualization Studio CGI Moon Kit](https://svs.gsfc.nasa.gov/4720/)。构建脚本 `tools/prepare_global.py` 将 LOLA 全球 64 px/° 高程图平均至 32 px/°，按纬度打包供浏览器按需读取。浏览器将真实数据重投影到每个 160 × 160 的球面方格地图；原始高程仍是经纬度格网，交互分片则采用每面 18 × 18 格的六面球面投影。各片接近等面积、不会在极区缩窄，但球面不可能由完全相同的正方形无缝铺满。三维视图以月球半径和分片实际水平尺度为基础，默认使用 4 倍高程夸张以保持地形可辨识。该原型仅用于科研展示，不用于真实月面任务决策。
